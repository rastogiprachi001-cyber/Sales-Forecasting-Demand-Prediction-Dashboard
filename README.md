
# Sales Forecasting & Demand Prediction Dashboard

## Objective
Develop a professional forecasting dashboard to predict future sales, identify demand trends, optimize inventory planning, and support business decision-making.

## Tools Used
- Power BI
- Excel
- Python / Pandas
- DAX
- SQL (Optional)

## Dataset Description
The dataset contains:
- Order details
- Product information
- Region and city
- Sales amount
- Marketing spend
- Forecasted vs actual sales
- Demand levels
- Seasonal indicators

## Key Analysis
- Sales trend analysis
- Seasonal demand forecasting
- Forecast error analysis
- Product-wise demand prediction
- Region-wise demand planning

## Dashboard Features
- KPI Cards
- Forecast vs Actual Trend
- Demand by Product
- Regional Demand Insights
- Seasonal Sales Patterns
- Stock Risk Indicators

## Key Insights
- High-demand products identified
- Seasonal sales spikes detected
- Forecast accuracy monitored
- Overstock and stockout risks highlighted

## Conclusion
This project demonstrates real-world sales forecasting and demand analytics using business intelligence techniques.
